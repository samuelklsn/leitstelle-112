# Fachliche Grundlagen

Hier steht, **warum** das Spiel sich so verhält, wie es sich verhält. Alle Zahlen sind Daten in
`content/base/` und keine Konstanten im Code. Jede Annahme ist als solche gekennzeichnet.

Fachleute aus Leitstelle, Rettungsdienst und Feuerwehr: Korrekturen sind sehr willkommen, gern über
die Issue-Vorlage „Fachliches Feedback“.
